This section reflects the connected puck. Reconnect after flashing or changing modes to verify what is currently running.

USB mode

Switching reboots the puck and re-enumerates USB (~2 s). WebUSB works in every mode except PS3 and the single-HID PlayStation modes; in Steam and Lizard it works even with Steam running (Chrome claims the vendor interface; Steam keeps the HID slots). Switch HORIPAD + WebUSB is PC-only.

Startup & identity

Off (default): every restart / fresh reconnect boots into Steam mode. On: remembers the last mode you selected.
On: OpenPuck presents itself as a Steam Machine's internal receiver (28DE:1305) instead of a Steam Controller Puck (28DE:1304). Takes effect on the next reboot.

Mode shortcuts

Hold the selected modifier (Quick Access or all four back paddles ) plus a face button or D-pad direction to switch mode without the WebUI. A is always Steam — that is the way back out of any mode. B / X / Y and D-pad directions are configurable (defaults: B=Lizard, X=Xbox, Y=Switch Pro). Modifier + trackpad click toggles the touchpad.

Button mapping

Each controller type only offers buttons that exist on that controller, and a dot on its tab marks the type of the current mode. Steam mode does its own remapping, so it has no tab here.

Lizard (desktop) bindings

Keyboard, mouse & media bindings for Lizard mode: each binding maps a controller input to a desktop action, checked top to bottom. Steam-mode seamless lizard (Steam closed) keeps the built-in default behavior and is not affected by this map. Pointer speed and glide are in Trackpad mouse below. Edits apply after Save to device. With current firmware there are three profiles of bindings, chosen below.

Trackpad mouse

Right-pad cursor in Steam-mode lizard (Steam closed) and in Xbox mode. Sensitivity is a divisor — lower = faster pointer. Glide = how long the cursor coasts after a flick. One setting, shared by the Xbox and Lizard profiles.

A short pulse on the clicked pad, once per press, in either trackpad D-pad mode. Independent of Trackpad haptics above.

Corrected (default) trims the gyro so Switch Pro mode matches a genuine Pro Controller and Steam mode (roll ×0.8, pitch/yaw ×0.9). Legacy sends the raw axes untrimmed — the pre-fix behavior, if you preferred the faster feel or tuned your in-game sensitivity around it.

This puck's firmware predates the gyro-mapping setting — update it to configure it.

In Switch Pro mode the game's HD rumble plays at the game's frequencies: both bands as one waveform on each grip, and the high band as tones on the trackpads. Grip rumble strength and HD trackpad strength scale them separately. Trackpad output is capped at −15 dB from 250–300 Hz, with gradual transitions outside that range.

Triggers

Emulated modes only; Steam mode passes the triggers to Steam Input untouched. Travel up to the deadzone reads as released, and travel at or past "Full press at" reads as a complete pull. Lower "Full press at" if a game made for DualSense resistive triggers doesn't register a full pull (firing while aiming, for example).

Rumble

Buzzes every connected controller for half a second at the current mode's strength.

Rumble follows the mode: HD rumble in Switch Pro mode, normal rumble everywhere else. Turn rumble on or off and set its strength per mode in Button mapping; HD trackpad strength is on the Switch tab.

This puck's firmware predates the rumble-shaping settings — update it to configure them.

Accel (raw): —

The controller streams motion data only when asked. Emulated modes turn it on when a controller connects; Steam and Lizard modes don't, so there the reading stays at zero until you turn it on here. Applies to every connected controller.

Raw SC2 accel (before scaling). This controller is a ±2 g sensor (~16384 = 1 g); the Switch report divides it by 4 to present the genuine ±8 g (4096 = 1 g) scale so the console's gravity-correction engages and the gyro stops drifting.

Status LED

SuperMini / Nice!Nano: 24, Nordic PCA10059: 11, Feather: 3 or 4 (255 = None)
Optional second LED pin (255 = None)
Flashes the configured pin(s) for 2 seconds to visually identify connected LEDs.

If testing your pin does not light up an LED, note that some boards have an onboard battery charger IC (TP4054) that pulses when no battery is attached and cannot be controlled via GPIO.

This puck's firmware predates the status LED settings — update it to configure them.

Backup & clone

Save this puck's controller pairings and every setting to a file, then restore them onto another puck. The other puck becomes a clone — any controller paired to this one connects to it with no re-pairing. (Also a plain backup: re-import after a factory erase to get everything back.)

Import overwrites all pairings and settings on the connected puck, then reboots it (~2 s — reconnect after). Tip: pair every controller to one puck, export once, then import onto each spare.

Maintenance

Reboot ONCE with the CDC serial console enabled (WebUSB goes away for that boot); auto-reverts on the next boot
Reboot into serial DFU (adafruit-nrfutil), then replug
Reboot into the UF2 mass-storage bootloader; drop a .uf2 on the drive
Wipe ALL bonds + settings and reboot to defaults. You must re-pair. Cannot be undone.
ERASE THE ENTIRE BOARD: firmware + all settings + bonds. The board reboots app-less and mounts as the UF2 drive on every boot until you re-flash OpenPuck. Debug only. Cannot be undone.

Firmware update (beta)

Updating from this page is still being tested and may not work correctly.

  • A bad image or an interrupted update can leave the puck needing a manual recovery: double-tap reset and drag a .uf2 onto the UF2BOOT drive it mounts.
  • A different build can change or reset settings. Export a backup first (Device, Backup & clone) if your puck is paired and configured.
  • The panel and the puck disconnect while the update applies.
